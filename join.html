Join 2026 Run Challenge

Participants only need to authorize Strava once.

For Participants

  1. Tap Sign in with Strava in the header.
  2. Log in to Strava and approve the challenge app once.
  3. After Strava sends you back, enter the display name you want shown.
  4. Choose Team A or Team B, then submit the join form.
  5. You are done. Your runs will appear after the GitHub workflow and next Strava sync complete.

No terminal, GitHub account, or code copying is needed. Garmin and Apple Watch runs count after they appear in Strava as runs.

For The Organiser

  1. New signups are handled by the Cloudflare Worker, which triggers the Add Strava Participant workflow.
  2. To move someone between teams, run Update Participant Team.
  3. To remove someone, run Remove Strava Participant.
  4. The daily sync runs at 7:00 am Singapore time and can also be triggered manually from GitHub Actions.

For the full architecture and API flow, read How the backend works.

Privacy Note

This setup links Strava to the challenge leaderboard. GPS maps, exact start and end locations, heart rate, cadence, power, and coordinates are not displayed.
