For Participants

  1. Enter your display name and activity source.
  2. Choose Team A or Team B.
  3. Tap Join with Strava.
  4. Log in to Strava and approve access once.
  5. After the Cloudflare join flow is enabled, you are done. No code copying is needed.

If the site still shows a one-time Strava code, the organiser has not switched on the automatic join flow yet.

For The Organiser

  1. Create and deploy the Cloudflare Worker in cloudflare-worker/.
  2. Update Strava's callback domain to the Worker domain.
  3. Set JOIN_WORKER_START_URL in app.js to the Worker's /start URL.
  4. Participants can then join directly from this page.

Privacy Note

This setup links Strava to the challenge leaderboard. GPS maps, exact start and end locations, heart rate, cadence, power, and coordinates are not displayed.
