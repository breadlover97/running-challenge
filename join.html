One-time Strava setup

Join Mileage Challenge

Participants only need to authorize Strava once.

Join with Strava Back to leaderboard
1x

For Participants

  1. Open the challenge website and tap Join with Strava.
  2. Log in to Strava and approve access.
  3. When you return to the challenge site, tap Copy Code.
  4. Send the code privately to the organiser with your display name and activity source.

Choose one source label: Garmin → Strava, Apple Watch → Strava, or Strava App.

For The Organiser

  1. Open Add Strava Participant.
  2. Click Run workflow.
  3. Paste the participant's display name, source label, and one-time code.
  4. Leave manual activities disabled unless you have agreed to allow them.
  5. After it succeeds, run Daily Mileage Challenge Update.

Privacy Note

This setup links Strava to the challenge leaderboard. GPS maps, exact start and end locations, heart rate, cadence, power, and coordinates are not displayed.
